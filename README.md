# راه‌اندازی سِنسا روی Cloudflare Workers

کاملاً رایگان. نه کارت بانکی می‌خواهد، نه هزینهٔ ماهانه.

---

## قبل از شروع، سه چیز را بدانید

**۱. آدرس `workers.dev` از ایران باز نمی‌شود.** زیردامنهٔ پیش‌فرض کلادفلر در ایران فیلتر است. برای تست به فیلترشکن نیاز دارید. وقتی دامنهٔ خودتان را وصل کنید، مشکل حل می‌شود.

**۲. برای کار با کلادفلر احتمالاً به فیلترشکن نیاز دارید.** هم برای پنل، هم برای دستورهای `wrangler`.

**۳. سقف رایگان برای شما بیش از کافی است:** روزی ۱۰۰ هزار درخواست و ۵ میلیون خواندن از دیتابیس. یک فروشگاه نوپا به کسری از این می‌رسد.

---

## قدم ۱ — نصب Node.js

اگر قبلاً نصب کرده‌اید، این قدم را رد کنید.

از `nodejs.org` نسخهٔ **LTS** را بگیرید، نصب کنید، و کامپیوتر را ری‌استارت کنید.

برای اطمینان، در ترمینال بزنید:

```
node -v
```

باید عددی مثل `v20.11.0` نشان بدهد.

---

## قدم ۲ — باز کردن پروژه

فایل zip را باز کنید و پوشهٔ `sensa-cf` را روی دسکتاپ بگذارید.

ترمینال را باز کنید:

- **ویندوز:** دکمهٔ Windows → تایپ `cmd` → Enter
- **مک:** Command + Space → تایپ `terminal` → Enter

بروید داخل پوشه:

```
cd Desktop/sensa-cf
```

بعد:

```
npm install
```

یکی دو دقیقه طول می‌کشد.

---

## قدم ۳ — ورود به کلادفلر

```
npx wrangler login
```

مرورگر باز می‌شود و از شما اجازه می‌خواهد. **Allow** را بزنید. بعد به ترمینال برگردید.

اگر مرورگر باز نشد یا صفحه بالا نیامد، فیلترشکن را روشن کنید و دوباره امتحان کنید.

---

## قدم ۴ — ساخت دیتابیس

```
npx wrangler d1 create sensa-db
```

خروجی چیزی شبیه این است:

```
[[d1_databases]]
binding = "DB"
database_name = "sensa-db"
database_id = "a1b2c3d4-5678-90ab-cdef-1234567890ab"
```

**آن رشتهٔ `database_id` را کپی کنید.**

حالا فایل `wrangler.toml` را با Notepad یا TextEdit باز کنید. این خط را پیدا کنید:

```
database_id = "اینجا-شناسه-دیتابیس-را-بگذارید"
```

و به‌جایش شناسه‌ای که کپی کردید را بگذارید:

```
database_id = "a1b2c3d4-5678-90ab-cdef-1234567890ab"
```

ذخیره کنید.

---

## قدم ۵ — ساخت جدول‌ها

```
npx wrangler d1 execute sensa-db --remote --file=./schema.sql
```

وقتی پرسید مطمئنید، `y` بزنید.

> کلمهٔ `--remote` مهم است. بدون آن، جدول‌ها فقط روی کامپیوتر خودتان ساخته می‌شوند، نه روی کلادفلر.

---

## قدم ۶ — گذاشتن رمزها

سه دستور، یکی‌یکی. بعد از هر کدام مقدارش را می‌پرسد.

```
npx wrangler secret put ADMIN_PASS
```
یک رمز قوی برای پنل مدیریت بزنید و Enter.

```
npx wrangler secret put JWT_SECRET
```
یک رشتهٔ تصادفی طولانی — فقط کیبورد را بی‌هدف بزنید، حدود ۴۰ کاراکتر. جایی یادداشتش کنید.

> موقع تایپ چیزی روی صفحه نشان داده نمی‌شود. طبیعی است.

اگر می‌خواهید نام کاربری مدیر را هم عوض کنید، در `wrangler.toml` خط `ADMIN_USER = "admin"` را ویرایش کنید.

---

## قدم ۷ — بالا آوردن سایت

```
npx wrangler deploy
```

آخرش یک آدرس می‌دهد:

```
https://sensa.یوزرنیم-شما.workers.dev
```

با فیلترشکن بازش کنید. **سایت شما بالا آمده است.**

بار اولی که صفحه باز شود، ۴۰ محصول و ۵ مقاله و صفحات قانونی خودکار ساخته می‌شوند.

---

## قدم ۸ — تست

- یک محصول به سبد اضافه کنید
- سفارش را تا آخر ثبت کنید (کد تأیید در کادر زرد نشان داده می‌شود)
- وارد پنل مدیریت شوید و سفارش را ببینید
- **رمز مدیر را عوض کنید** — از دکمهٔ «تغییر رمز»

اگر بالای پنل نوشته بود **«متصل به سرور»**، یعنی همه‌چیز درست کار می‌کند.

---

## قدم ۹ — وصل کردن دامنه

این مرحله را بعد از خرید دامنه انجام دهید. **بدون دامنه، سایت از ایران باز نمی‌شود.**

### الف) خرید دامنه

**برای `.ir`:** اول در `irnic.ir` ثبت‌نام کنید و شناسه بگیرید (کد ملی و موبایل لازم است). بعد از `parspack.com` یا `iranserver.com` دامنه بخرید. سالی حدود ۵۰ هزار تومان.

**برای `.com`:** از `namecheap.com` یا `cloudflare.com` — پرداخت ارزی لازم دارد.

> اگر دامنهٔ `.com` را مستقیم از خود کلادفلر بخرید، مراحل بعد خودکار انجام می‌شود.

### ب) اضافه کردن دامنه به کلادفلر

۱. وارد `dash.cloudflare.com` شوید
۲. **Add a site** را بزنید
۳. دامنه‌تان را بنویسید
۴. پلن **Free** را انتخاب کنید
۵. کلادفلر دو **نیم‌سرور** به شما می‌دهد، چیزی شبیه:

```
adam.ns.cloudflare.com
kate.ns.cloudflare.com
```

هر دو را یادداشت کنید.

### ج) تغییر نیم‌سرورها

**برای دامنهٔ `.ir`:**

۱. وارد پنل `irnic.ir` شوید
۲. دامنه‌تان را انتخاب کنید
۳. بخش **ویرایش سرویس‌دهنده‌های نام** یا **DNS**
۴. نیم‌سرورهای فعلی را پاک کنید و دو تای کلادفلر را وارد کنید
۵. ذخیره کنید

**برای `.com`:** همین کار را در پنل جایی که دامنه را خریدید انجام دهید.

بین چند ساعت تا ۲۴ ساعت طول می‌کشد. کلادفلر ایمیل می‌زند که فعال شد.

### د) وصل کردن دامنه به سایت

۱. در پنل کلادفلر، بخش **Workers & Pages**
۲. روی `sensa` کلیک کنید
۳. تب **Settings** → **Domains & Routes** → **Add** → **Custom domain**
۴. دامنه‌تان را بنویسید: `sensa.ir`
۵. تأیید کنید

چند دقیقه بعد سایت روی دامنهٔ خودتان بالا می‌آید، با SSL خودکار. **حالا از ایران هم باز می‌شود.**

---

## قدم ۱۰ — وصل کردن پیامک

بعد از اینکه دامنه را گرفتید و در پنل پیامکی ثبت‌نام کردید:

```
npx wrangler secret put SMS_PROVIDER
```
بزنید: `kavenegar` یا `smsir`

```
npx wrangler secret put SMS_API_KEY
```
کلید پنل پیامکی

```
npx wrangler secret put SMS_TEMPLATE
```
نام الگویی که در پنل پیامکی ساختید

بعد یک بار دیگر:

```
npx wrangler deploy
```

از این به بعد کد واقعاً پیامک می‌شود و کادر زرد خودش محو می‌شود.

---

## به‌روزرسانی سایت در آینده

هر وقت فایل `public/index.html` را عوض کردید:

```
npx wrangler deploy
```

**اطلاعات پاک نمی‌شوند.** دیتابیس D1 جداست و با استقرار دوباره دست نمی‌خورد.

---

## پشتیبان‌گیری

**راه ساده:** از پنل مدیریت، دکمهٔ **پشتیبان JSON** و **خروجی اکسل**. هفته‌ای یک بار.

**راه کامل:**

```
npx wrangler d1 export sensa-db --remote --output=backup.sql
```

فایل `backup.sql` کل فروشگاه شماست. جای امنی نگهش دارید.

---

## خطاهای رایج

**`wrangler login` باز نمی‌شود**
فیلترشکن را روشن کنید.

**`D1_ERROR: no such table`**
قدم ۵ را انجام نداده‌اید، یا `--remote` را ننوشته‌اید.

**سایت بالا می‌آید ولی محصولی نیست**
یک بار صفحه را رفرش کنید. بار اول دیتابیس پر می‌شود و چند ثانیه طول می‌کشد.

**در پنل نوشته «حالت محلی»**
یعنی سایت به ورکر وصل نیست. آدرس را چک کنید که همان آدرس ورکر باشد، نه فایل روی کامپیوتر.

**`Cannot read properties of undefined (reading 'prepare')`**
`database_id` را در `wrangler.toml` نگذاشته‌اید. برگردید به قدم ۴.

**رمز مدیر را فراموش کردم**
```
npx wrangler secret put ADMIN_PASS
```
یک رمز جدید بزنید و دوباره `npx wrangler deploy`.

## ترتیب کارها

**امروز:** قدم‌های ۱ تا ۸ — سایت روی کلادفلر بالا می‌آید و با فیلترشکن تستش می‌کنید.

**این هفته:** دامنه بخرید و قدم ۹ را انجام دهید. از اینجا به بعد سایت از ایران باز می‌شود.

**بعدش:** پیامک را وصل کنید و فرآیند نماد اعتماد را شروع کنید.
