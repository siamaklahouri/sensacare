# برنامهٔ اندرویدِ SLTech (فایل APK)

برنامهٔ اندروید یک **TWA** است: پوسته‌ای نازک که همان کارتابلِ روی
`sltech.ir` را بی‌نوارِ آدرس نشان می‌دهد. هیچ کدِ جداگانه‌ای ندارد —
هر چه در کارتابل عوض شود، همان لحظه در برنامه هم عوض شده است و
نیازی به ساختنِ دوبارهٔ APK نیست.

ساختنِ دوبارهٔ APK فقط وقتی لازم است که نام، نشانه، رنگ یا نشانیِ
شروعِ برنامه عوض شود.

> **برنامهٔ نصب‌شده را یک بار دوباره بسازید.** مانیفستی که پوسته از
> رویش ساخته شده بود `/siamak/app.webmanifest` بود — یعنی محدوده‌اش
> (`scope`) فقط کارتابلِ یک نفر، در حالی که برنامه از `/login` باز
> می‌شود. اندروید آدرسِ بیرونِ محدوده را «تأییدنشده» می‌بیند و نوارِ
> آدرس را بالای صفحه می‌گذارد؛ یعنی برای همهٔ کاربرهای دیگر، برنامه
> شبیهِ مرورگر بوده نه برنامه. حالا `https://sltech.ir/app.webmanifest`
> هست که به هیچ کارتابلی بند نیست (`scope: "/"`, `start_url: "/login"`)
> و `twa-manifest.json` به همان اشاره می‌کند. تا APK دوباره ساخته
> نشود، نسخهٔ روی گوشیِ کاربرها همان رفتارِ قبلی را دارد.

## چه چیزهایی این‌جاست

- `twa-manifest.json` — همهٔ مشخصاتِ برنامه (نام، بسته، رنگ‌ها،
  نشانه‌ها، نشانیِ شروع).
- `assetlinks` — در `public/.well-known/assetlinks.json` نشسته، نه
  این‌جا. اثرِ انگشتِ کلیدِ امضا داخلش است و **باید** روی دامنه سرو
  شود، وگرنه اندروید برنامه را «تأییدنشده» می‌داند و یک نوارِ آدرس
  بالای صفحه می‌گذارد.

## چه چیزی این‌جا نیست، و نباید باشد

`android.keystore` و رمزش. کلیدِ امضا جایی بیرونِ این مخزن می‌ماند.
اگر گم شود، نسخهٔ بعدیِ برنامه دیگر «همان برنامه» حساب نمی‌شود و
کاربر باید اول قبلی را پاک کند.

> **یک بار همین اتفاق افتاد.** کلیدِ اول در یک محیطِ موقت ساخته شده
> بود و با رفتنِ آن محیط از بین رفت. کلیدِ تازه (آبان ۱۴۰۵) روی خودِ
> سرور است: `/root/android.keystore`. دو چیز لازم است و هیچ‌کدام
> به‌تنهایی کافی نیست — خودِ فایل، و رمزش که فقط دستِ صاحبِ سرور است.
>
> `bash server/ops.sh env` از هر دو فایلِ حساس پشتیبانِ رمزشده
> می‌گیرد (تنظیمات و همین کلید). خروجی‌اش را **بیرونِ سرور** نگه
> دارید؛ اگر سرور از دست برود، این تنها راهِ برگرداندنِ کلید است.

## وضعیت: نیمه‌کاره (آبان ۱۴۰۵)

کلیدِ تازه ساخته شده و روی سرور است، ولی **APK هنوز با آن ساخته نشده**.
دلیلش فنی نبود: دانلودِ ابزارِ ساخت از این شبکه بارها نیمه‌کاره ماند.

- اثرِ انگشتِ کلیدِ تازه (برای وقتی که APK ساخته شد):
  `38:DB:F1:64:0E:05:CE:21:46:2D:FC:1C:02:18:2A:F1:BF:58:DC:83:02:BC:04:4C:18:B3:F8:64:D3:82:14:60`
- `assetlinks.json` عمداً هنوز اثرِ انگشتِ **قدیمی** را دارد، چون APKِ
  روی سایت با همان کلیدِ قدیمی امضا شده. اگر زودتر عوضش کنیم، تأییدِ
  برنامه برای کاربرهای فعلی هم می‌شکند و وضع بدتر از حالا می‌شود.
- پس ترتیبش این است: اول APK ساخته شود، بعد در یک استقرار **هر دو**
  با هم بروند — فایلِ APK و اثرِ انگشتِ تازه.

ادامهٔ کار از این‌جا:

```sh
tmux new -s build
cd /opt/sltech/app/android
cp /root/android.keystore ./android.keystore
export GRADLE_OPTS="-Dorg.gradle.jvmargs=-Xmx900m -Dorg.gradle.daemon=false"
bubblewrap update        # به سؤالِ JDK: No، مسیر: /usr/lib/jvm/java-17-openjdk-amd64
bubblewrap build --skipPwaValidation
```

JDK 17 از قبل با apt نصب شده. آنچه مانده فقط دانلودِ Android SDK است.

## ساختنِ دوباره

```bash
npm i @bubblewrap/cli
# کلید را کنارِ twa-manifest.json بگذار (android.keystore)
npx bubblewrap update --appVersionName=1.0.1
npx bubblewrap build --skipPwaValidation
# خروجی: app-release-signed.apk
```

اگر اثرِ انگشتِ کلید عوض شد، `public/.well-known/assetlinks.json` هم
باید با اثرِ انگشتِ تازه به‌روز شود:

```bash
keytool -list -v -keystore android.keystore -alias sltech | grep SHA256
```

فایلِ ساخته‌شده در `public/sltech.apk` می‌نشیند و از
`https://sltech.ir/sltech.apk` دانلود می‌شود.

## شمارهٔ نسخه

`appVersionName` و `appVersionCode` از روزِ اول روی `1.0.0` و `1`
مانده‌اند. اندروید برای نصبِ نسخهٔ تازه روی نسخهٔ قدیمی، **باید**
`appVersionCode` بزرگ‌تر ببیند — وگرنه نصب را رد می‌کند و کاربر باید
اول برنامه را پاک کند. پس هر بار که APK را دوباره می‌سازید:

- `appVersionCode` را یکی بالا ببرید (۱ → ۲ → ۳ …) — این عدد است و
  هیچ‌وقت پایین نمی‌آید.
- `appVersionName` را هم مثلِ نسخه‌های معمولی بالا ببرید (`1.0.1`).

`bubblewrap update --appVersionName=...` فقط نام را می‌گذارد؛ عدد را
خودتان در `twa-manifest.json` بالا ببرید.
